# SurgeryCraft 病例数据与三维样例说明

更新日期：2026年10月31日 · 当前样例版本：第126例 v3

本目录保存 SurgeryCraft 的原始外科病例资料，以及基于第126例制作的三维交互样例。合作目标是将病例中的病史、检查、手术与随访信息转化为可查阅、可交互、可记录过程的虚拟医院任务，为后续医疗智能体研究提供场景基础。

目前已有 **150 个原始病例压缩包**，按 `001` 至 `150` 编号，每个压缩包对应一个病例文件夹。已完成的交互样例覆盖第126例；其余资料用于后续病例整理和场景扩展。

## 第126例是什么

样例依据张少博、余仁斌的《内脏完全反位腹腔镜胆囊切除术一例》（《肝胆胰外科杂志》，2024，36(3)：180–181）改编。原报告描述一位84岁男性，因上腹痛伴发热就诊，影像记录内脏完全反位，肝脏和胆囊位于患者左侧、胃和脾脏位于患者右侧，并接受腹腔镜胆囊切除术。

交互样例以“上腹痛伴发热 · 84岁男性”为病例入口。医院流程先开放病史、检查和影像资料，完成前置任务后再开放历史手术、病理和随访记录；原文未记载的信息保留为未知。场馆、交互任务和动画由项目制作，演示中的操作不会改变原报告已经发生的结局。

## 当前版本已完成什么

| 模块 | 已实现的内容 |
| --- | --- |
| 医院病例流程 | 在 IMPF 外科医院中进入病例、问诊、查阅报告、完成决策任务和回顾术后记录；原病例流程包含规则评分与轨迹记录 |
| 病例与证据 | 提供结构化病例、原文证据索引、未知信息标记及分阶段开放逻辑 |
| 腹腔三维术野 | 提供肝胆、胃脾、胰腺、十二指肠及示意胆道和血管；支持结构选择、显隐、聚焦、透明度调整和腹腔镜视角 |
| 手术教学动画 | 展示定位、显露、辨认、学习核对、夹闭、离断、胆囊离床和取出八个阶段；可暂停、继续和切换阶段 |
| 可编辑开发材料 | 提供 Blender 工程、GLB 模型、网页源码、建模脚本、验证记录和来源许可 |

v3 的肝脏、胆囊、胃、十二指肠和胰腺采用 BodyParts3D 参考器官网格，经 Blender 镜像、表面处理和材质调整，适配本例的器官侧别。胆道、血管细节、器械和操作轨迹仍为教学设计。**当前模型属于参考解剖适配，尚无患者 CT 分割重建或真实组织切割仿真，形态与术野表现仍需继续精修。**

## 怎样体验和继续开发

1. 下载 `case-126-v3/index.html`，保存到电脑后用支持 WebGL 的桌面 Chrome 或 Edge 打开。GitHub 文件页面用于查看或下载文件，不会直接运行演示。体验时无需安装 Blender、Node.js 或输入 API 密钥。
2. 打开后先查看三维术野：拖动旋转、滚轮缩放、点选器官，或切换腹腔镜视角。
3. 点击“播放演示”。第四阶段会暂停，完成两个学习勾选后再继续播放。这里的勾选属于交互教学步骤，不代表临床手术安全条件已经满足。
4. 点击顶部“医院病例流程”，在病例库搜索 `84`，选择“上腹痛伴发热 · 84岁男性”，场馆选择 IMPF 外科医院。
5. 需要继续开发时，下载完整交接 ZIP 并解压，阅读其中的 `先读我.txt` 和 `使用与开发说明.md`。

交接包解压后的主要开发文件位于以下位置：

| 路径 | 内容 |
| --- | --- |
| `source/content/assets/blender/` | 可编辑的 `.blend` 工程及教学关键帧 |
| `source/content/assets/models/` | 网页使用的 `.glb` 模型、资产说明与许可 |
| `source/surgical-view/` | 三维查看器及交互源码 |
| `source/tools/blender/` | 可重复生成模型的脚本 |
| `source/content/cases/cmcr-1654623/` | `case.json`、`evidence.json` 和病例说明 |

开发包保留了制作样例时的医院内容快照。建议在独立目录中展开，按需将病例改动合入当前 SurgeryCraft 项目；构建所需 ClinicalCraft 引擎及环境要求见包内说明。

## 后续精修与研究工作

以下为下一阶段计划，尚未作为本版完成成果：

| 优先方向 | 具体工作与检查目标 |
| --- | --- |
| 解剖审核与模型精修 | 请外科合作者核对镜像侧别、肝脏外形、胆囊附着区域和胆道血管关系，形成逐项修改清单；区分原文事实与通用参考解剖 |
| 术野与组织表现 | 改善组织层次、器官接触关系、表面细节、材质和光照，检查不同观察角度的遮挡与显露效果 |
| 动作与器械表现 | 精修牵引、夹闭、离断、离床和取出轨迹，检查器械接触、组织穿插和动作连续性 |
| 病例流程与三维动作衔接 | 将结构识别、学习检查和操作事件接入统一任务状态、轨迹和评分，明确错误操作及失败分支 |
| 智能体评测设计 | 在专家审阅后定义可观测信息、允许动作、参考答案和评分规则，再开展真实模型调用与重复实验 |

当前医院病例流程和三维术野共享入口与病例身份，**三维操作尚未计入原病例评分**。已完成的技术验证包括8项状态测试、模型嵌入一致性检查、Blender 关键帧检查和浏览器交互检查，记录见 [validation.json](case-126-v3/validation.json)。浏览器实测使用本地 HTTP 预览；`file://` 双击方式未在受控浏览器中实测，离线资源已作静态检查。

模型与动画尚未经临床专家审核；现阶段适合合作者查看、讨论和迭代。原病例参考流程的100分来自脚本验证，不是医疗大语言模型实验成绩。三维演示直接呈现解剖与结局信息，后续开展盲测时需另行控制信息开放。
